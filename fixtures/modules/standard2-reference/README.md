# Standard 2 Reference Fixture

This directory is a test-only Greenfield Standard 2 fixture for Phase 7I source provenance closure.

It is not a production Marketplace module and must not be published or installed as product catalogue authority. The fixture exercises host-mediated Standard 2 runtime declarations: dependency planning, capability projection, service and API registration, hooks, jobs, storage allocations, UI contributions, and a declarative markdown service contract.

The canonical host import manifest is `greenfield.manifest.json`.
