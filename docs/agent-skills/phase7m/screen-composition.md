# Compose a Modula screen

Do not start by drawing boxes.

1. List the screen’s user jobs.
2. Rank content/actions: primary / secondary / tertiary.
3. Identify canonical components already available.
4. Write a text hierarchy before layout.
5. Choose reference patterns and record why (`phase7m-visual-gallery.md`).
6. Compose without decorative surfaces first.
7. Add only surfaces needed for grouping/chrome.
8. Check information density.
9. Check one-handed reach where relevant.
10. Check keyboard/web layout.
11. Test Appearance modes and Surface Types.
12. Test real API data, empty, loading, and error.
13. Capture phone + wide web screenshots.
14. Do not accept until screenshot review passes.
