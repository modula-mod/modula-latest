## Why A

Direction A matches the founder App Store stills without cloning them: artwork owns the frame, copy sits in the image, product identity is attached to the same story, then dense rows, an icon shelf, an intentional Coming Soon story, and a visual browse grid. It keeps install CTAs readable, survives large text, and maps to a two-column desktop without becoming a phone column.

Direction B is more cinematic but weaker on information clarity, web cropping, and overlay contrast.

Direction C is the strongest magazine split, but the overlap identity card risks becoming another generic container on small phones.

**Recommended: A — Editorial Story**
