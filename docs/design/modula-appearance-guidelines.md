# Modula Appearance Guidelines

- Theme is multidimensional.
- Colour Family does not define material.
- Accent does not define canvas.
- Surface Type does not change layout.
- Accessibility may override visual preferences.
- Text posts remain visually open.
- Media may use backlight.
- Link previews remain contained.
- Glass is selective.
- Native material is platform-specific.
- OLED canvas is true black.
- Screens must not invent tokens.

The interface should feel social, native, modular, calm, premium, content-first, spatially coherent and recognisably Modula.

Avoid administrator dashboards, debug component catalogues, universal rounded cards, and blurred fog layers.
