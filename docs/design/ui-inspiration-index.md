# UI inspiration index

These documents capture external product craft as Modula remaps. They are not design-system forks, clone briefs, or dependency requests.

## Inspiration remaps

- [X / Twitter inspiration remap](./x-twitter-inspiration.md) - dense social reading, mode bars, hairline separators, and micro-feedback mapped to Profile-OS plus modules.
- [Apple Liquid Glass / HIG inspiration remap](./apple-liquid-glass-inspiration.md) - glass as navigation material, content solidity, and accessibility mapped to Modula Surface Types.
- [Forge Builder inspiration remap](./forge-builder-inspiration.md) - builder workflows mapped to Forge, module manifests, previews, and permission honesty.

## Shared rules

- Modula Teal `#369CAA` remains the brand accent through tokens.
- OLED canvas, hairline separators, and low chrome are compatible directions when they preserve readability.
- Inspiration must be translated into Modula primitives, theme tokens, Profile-OS, and module boundaries.
- Do not copy proprietary fonts, logos, design systems, Bluesky ALF, or third-party product implementation details.
