# Phase 7M-B5 — Direction M: Modula Native Social OS

B4’s A/B/C exercise was useful. **None of them is selected wholesale.**

Working name: **Direction M — Modula Native Social OS**

This is not an averaging exercise. It is a refined language built from the strongest principles, with an explicit trace for every decision.

Founder target mix (binding): **Dense Social OS + Native Editorial + selective Spatial Modula**, with spatial treatment concentrated in **shell / chrome / interactions**, not in the content itself.

---

## Characteristics

- CONTENT FIRST
- dense but calm
- strong typography
- minimal card framing
- rich media
- scarce accent colour (`#369CAA` is a verb, not a fill)
- platform-native controls
- custom Modula shell
- native materials where useful (see liquid glass policy)
- modules feel like products
- social feed feels alive
- fast interaction
- subtle motion
- strong visual identity

## Decision trace (which research → which rule)

| Decision | Comes from | Explicitly not from |
| --- | --- | --- |
| Home is a continuous document of posts (hairlines, no post cards) | Threads Home, X compact hierarchy, constitution “content first” | 7M-B2 boxed feed; Direction B’s extra air around every cell |
| Several posts per viewport | Threads, X | Instagram’s media-only viewport as the default Home |
| Stories as presence rail; **Focus Halo** as Modula differentiator | Instagram rail (job), Modula invention (halo) | Instagram gradient ring recipe |
| For You / Following / Modules as modes, not page titles | Bluesky custom feeds, X/Threads mode control, Apple HIG (tabs vs filters) | LinkedIn “Start a post” dashboard |
| Reaction: tap = Like; long-press proximity row of Like/Love/Laugh/Fire | LinkedIn/IG long-press; animation-samples Grid Magnification **behaviour** | 8 equal bloom icons; Reddit upvotes |
| Composer `+` is a tool launcher (sheet + interruptible toolbar) | LinkedIn one-line → sheet; animation-samples Custom Toolbar | Equal visual blocks for every tool |
| Product Hub is editorial (Featured / New / Made by Modula / Your modules) | App Store Today+shelves, Spotify library, WWDC26 Creative Assets | Registry pills Installed/Available/Updates; KIND_SECTIONS dump |
| Module artwork independent of OS accent | App Store identity imagery, Airbnb photo-as-object, Reminders list colour ≠ system tint | Turquoise cube for every module |
| Auth is identity → best method → alternative → recovery | Apple AutoFill / Sign in with Apple; Create Account already progressive | All fields as equal blocks (rejected 7M-B2) |
| Navigation candidate: **NAV-C Hybrid** — native destinations + Modula accessory | Apple HIG (tabs = areas, actions = toolbar); Linear “own chrome if needed”; Instagram pill as optional chrome | NAV-B glass sampling; mixing Create into tabs indiscriminately |
| Spatial/glass only on chrome and transient controls | WWDC26 UI layer vs content layer; 7M-B2 bleed failure | Direction B as a whole-app glass demo |
| Density of lists after install (Vault Notes) | Apple Notes, Things, Linear | Notion SaaS grey; Craft card-stack as the OS |
| Android Compose + iOS SwiftUI + web DOM as expressions of one contract | Expo UI 57 universal API + platform packages | iOS design + Android approximation |
| Motion only when it communicates | animation-samples audit; constitution | Rope physics; Reanimated because it exists |

Direction A contributed: typographic Home, native controls, editorial Hub, scarce accent.  
Direction B contributed: owned chrome *option*, staged module identity, spatial **only** as shell.  
Direction C contributed: maximum information, Modules-in-social, compact nav thinking.

Direction M keeps A’s content, C’s density, and B’s chrome restraint.
