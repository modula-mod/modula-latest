# Modula Profile Guidelines

- Profile is the centre of Modula.
- Identity belongs inside Profile.
- Owner and public views share components.
- Tabs are registry-driven.
- Core tabs are not module implementations.
- Modules may contribute tabs later.
- Profile visibility UI is not backend security.
- Text posts remain visually open.
- Surface Type does not change information architecture.
- Profile layouts change emphasis, not core capabilities.
- Profile remains usable without modules.
- Profile remains usable offline.

The profile should feel social, personal, modular, expressive, native, premium, content-first and user-controlled.

Do not make profile screens look like settings pages, raw database records, dashboards or clones of existing social networks.
