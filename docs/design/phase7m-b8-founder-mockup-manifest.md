## Per-mockup notes (condensed)

### FM-VIDEO-001 — Video post full flow
- **Visual:** Dark glass; media hero; right Action Rail (like/comment/save/share).
- **Interaction:** Tap play/pause; long-press like → reaction bar; swipe-up comments; expand → full player.
- **Hierarchy:** Media > rail > caption; chrome non-intrusive.
- **Material:** Blur overlays for picker/comments/player chrome.
- **Gesture:** Tap media, LP rail heart, horizontal reaction swipe, vertical comments, expand icon.
- **Motion:** Physical morph; haptics on LP/select; count update.
- **A11y:** Large targets; high contrast; Reduce Motion → cut morph to fade/instant.
- **Affected:** `video-post-renderer`, `post-action-rail`, `reaction-picker`, `comments-surface`, `media-full-player`.
- **Decision:** REFINE existing Post V2 grammar to match mockup density/geometry.
- **Deviation:** Mock counts are illustrative; UI must bind real engagement counts only.

### FM-APPLOCK-001 — PIN unlock + Security settings
- **Visual:** Dark abstract bg; amber accents; 6-dot PIN; telecom keypad; Local App Lock card.
- **Interaction:** Digit entry; Use Password / Emergency; unlock method tiles; auto-lock; step-up toggles.
- **Security copy:** Local-only; never sent to Modula servers.
- **Affected:** NEW `AppLock` screens + Security settings section.
- **Decision:** NEW (local SecureStore). Biometric via `expo-local-authentication` only if admitted; else Face ID affordance → DEFER with documented stub.
- **Deviation:** No server-side PIN storage. Wallet/purchase step-up may no-op where features absent.

### FM-MUSIC-001 — Music interaction flow

- **Decision:** REFINE; only real playback controls (no decorative fake transport).
