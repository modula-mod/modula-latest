# Material Usage Rules

Use `MaterialSurface` and its wrappers:

- `MaterialBackground`
- `MaterialCard`
- `MaterialNavigationBar`
- `MaterialFloatingControl`

Approved initial glass/native roles:

- app header;
- bottom tab bar;
- drawer;
- Composer Tools panel;
- selected floating controls.

Disallowed initial glass/native use:

- every feed post;
- entire profile screen;
- long text surfaces;
- full-screen settings background.

Reduce Transparency disables blur and native glass.

Increase Contrast strengthens borders and avoids low-contrast neomorphic treatment for critical controls.
