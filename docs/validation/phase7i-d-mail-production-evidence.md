## SMTP Submission

Port `587/tcp` is the production submission path for Greenfield mail. The worker runtime uses:

```text
MODULA_MAIL_TRANSPORT=smtp
MODULA_MAIL_FROM=no-reply@modula.digital
MODULA_SMTP_HOST=mail.modula.digital
MODULA_SMTP_PORT=587
MODULA_SMTP_SECURE=false
MODULA_SMTP_REQUIRE_TLS=true
MODULA_SMTP_TLS_REJECT_UNAUTHORIZED=true
MODULA_SMTP_PASSWORD present=true
```

Credential values are stored only in protected environment configuration and are not recorded here.
