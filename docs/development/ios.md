# iOS Development

## Generate native project

```bash
pnpm prebuild:clean
```

On macOS, Expo installs CocoaPods and creates `ios/Modula.xcworkspace`.

On Linux, Expo still generates the `ios/` project sources, but skips CocoaPods installation (no Xcode). Run `pod install` on macOS before opening the workspace.

Open:

```bash
open ios/Modula.xcworkspace
```

Use the workspace, not the `.xcodeproj`, because CocoaPods dependencies integrate through the workspace.

## Run

```bash
pnpm ios
```

Bundle identifier: `digital.modula.app`

## Notes

- Requires macOS + Xcode for simulator and device builds
- On Linux hosts, `ios/` can still be generated by prebuild, but compilation is NOT TESTED without Xcode
- Do not enable OTA update publishing during Phase 0
