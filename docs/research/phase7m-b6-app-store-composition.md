# Phase 7M-B6 — App Store composition study

Founder-supplied App Store screenshots are **research only**. They are not shipping assets and must not be overlaid into the product.

## Modes studied

| Mode | Extracted pattern | Modula expression |
| --- | --- | --- |
| Today | Editorial hero, then rows | Featured hero + New for Modula rows |
| Games / Apps | Large title, category chips, hero, compact rows with right-aligned CTA | Large Product Hub title, browse tiles in search, ModuleRow |
| Arcade | Immersive hero + ranked rows | One featured hero only; no fake ranks |
| Search | Suggested rows + colourful browse tiles | Suggested + quieter Modula category tiles |
| App Detail | Identity + sticky Install, preview carousel, What’s New, privacy, information list | Module Detail continuous sections + sticky Install |

## What we did not copy

- Apple wordmarks, Today/Games/Apps/Arcade/Search tabs
- Pixel layout, SF-only type recipes, rainbow category gradients
- Price/Get commerce chrome as decoration
- Pixel-perfect clones of any screenshot

## Rhythm

Alternate hero / rows / shelf / collection. Avoid card → card → card.
