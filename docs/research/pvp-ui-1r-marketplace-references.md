## Products / marketplaces

1. Apple App Store (Today, Games, Apps, Arcade, Search, product detail)
2. Google Play Store (Apps / Games, For You as default, Material 3)
3. Figma Community (plugins, widgets, templates)
4. Notion Marketplace / Template Gallery
5. Visual Studio Code Extension Marketplace
6. Shopify App Store
7. Refero design research library
8. Mobbin screen library (homepage / explore public; full screen library login-gated)
9. Expo UI Examples (SDK 57 source, MIT)

## Pattern families extracted

1. Editorial hero that owns the viewport
2. Dense product rows with small CTAs
3. Search as a destination
4. Visual category / browse grid
5. Install / Open / Update state
6. Native navigation chrome vs content
