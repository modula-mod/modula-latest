# Bluesky Inspiration Policy

The previous Bluesky-based Modula repository and upstream Bluesky source may be inspected for inspiration, but must not become the new foundation.

## Permitted uses

- Study feed information density
- Study post composition hierarchy
- Study accessibility patterns
- Study large-list performance strategies
- Study image loading behaviour
- Study route naming concepts
- Study profile/feed interaction patterns
- Study moderation and safety UX
- Study optimistic update concepts
- Study how protocol APIs are isolated

## Forbidden uses

- Copying the complete application shell
- Copying the root provider tree
- Copying the global gesture architecture
- Copying navigation wholesale
- Copying Bluesky account/session assumptions
- Copying AT Protocol directly into UI components
- Copying large components with internal Bluesky dependencies
- Copying files before checking their licence and dependency graph
- Preserving Bluesky terminology in Modula interfaces
- Using Bluesky’s design system as Modula’s theme engine

## Rule

> Study behaviour and architecture, then implement the smallest Modula-native equivalent.

Every copied or adapted source fragment must include provenance and licence review.
