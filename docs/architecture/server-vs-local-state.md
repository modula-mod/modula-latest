# Server State Vs Local State

Server-shaped state:

- sessions
- accounts
- profiles
- posts
- feeds
- post statistics
- follows
- saved posts
- activity
- discovery results
- creator information
- public module previews

Device-local application preferences:

- appearance
- accessibility overrides
- profile-tab order
- profile layout
- selected development data mode
- non-sensitive interface preferences

Server-shaped state is query-owned even when locally simulated. Local preferences remain in dedicated presentation or appearance storage.
