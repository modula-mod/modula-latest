# Intelligence architecture — implementation phases

Canonical companion to `intelligence-architecture.md`.

## Phase A — Make the existing product real

1. Stabilise navigation, drawers, overlays, native interactions  
2. Complete authentication, backend persistence, sessions  
3. Reactions, comments, reposts, follows, notifications fully functional  
4. Appearance globally (themes, OLED, accents, surfaces, a11y)  
5. Unify owner and public profiles  
6. Automated + physical-device testing  

## Phase B — Establish the platform

1. Finalise module manifest + package standard  
2. GitHub-backed Registry  
3. Install / update / disable / remove  
4. Permission prompts + isolation  
5. Module-provided settings  
6. Module Template + Forge foundations  
7. Universal Command Layer  

## Phase C — Attention and privacy

1. Real Focus policy engine (replace settings-only prototype)  
2. Focus → navigation, feeds, chat, notifications, Board, GAIA  
3. Focus Halo  
4. Glass Privacy enforcement  
5. Chat Assist permissions + actions  
6. Quiet Send + focus-aware messaging  
7. Privacy and action audit records  

## Phase D — Introduce intelligence safely

1. GAIA read-only contextual assistant  
2. User-confirmed commands  
3. AKI claim + action verification  
4. Ledger and Replay  
5. Circuit Memory with user controls  
6. Kaizen feedback + review pipeline  
7. AGI Governor policies + autonomy levels  
8. Claims Graph  
9. Foundry dataset + training pipeline (gate before any train)  

## Phase E — Expand the ecosystem

1. Vault Notes · Tasks · CRM  
2. Marketplace + Module Forge  
3. Teams  
4. Automations  
5. DIMON  
6. Gaia Atlas  
7. Advanced GAIA autonomy  

**Current host work:** Phase A/B craft + Phase C/D **Preview surfaces** that teach the architecture without claiming production intelligence.
